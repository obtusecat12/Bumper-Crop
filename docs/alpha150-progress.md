## 每轮停工与保存规则

- 从开始执行起计时。阶段 1、6 最多 60 分钟；其余最多 90 分钟。额度不足时允许更早停工。
- 每 15 分钟，或完成一个独立模块时，保存可恢复的增量；不要等整个基地做好才提交。
- 最后 20 分钟只用于必要截图、保存、更新本文件和报告，不再启动新的建模、贴图生成或长烘焙。
- 到硬截止时间立即停止扩展任务。停止仍在计算的子任务/进程，并保存已完成的输出。
- 可运行的修改正常提交 main；未完成的独立源码/烘焙输入可以保存到 art-source/alpha150/checkpoints 下且不接入运行时。不要将半改坏的 main.js 推送。
- 推送前只处理实际涉及文件和最新远端差异，不扩大为无关核对。禁止 git add 全目录而夹带其他开发者的文件。
- 每次记录：提交 SHA、已完成模块、截图路径、进行中的文件、下一步第一条具体动作、阻塞项。计时结束前不要只留下“继续优化”。
- 用量上限不是可以读取的精确倒计时，90 分钟也不保证不会触发额度限制。因此保存优先于扩大并行量；遇到限额不循环重试。
- 六次计划运行结束仍有未完成项时，明确报告缺口；不要自行建立无限循环任务。

- 按用户平面图设计约 300×260m、外接矩形 78,000m²的独立基地；这是设计尺度，不是官方测绘数据。四署、五片区和南部扩建依图拓扑排列。
- 拟用 dist/alpha150-plan.js 作为可见几何、地图、碰撞、灯光与烘焙的共同来源；房间/走廊再切为不超过约 24m 的区块。
- 兼容现有关卡 API：独立 scene，state.level 保持 1，mode 为 alpha。提供 ready/update/blocked/safe/supportAt/landingAt/headAt/map/dispose、入口和退出点。
- 拟在 Level 1 的 x=640..940、z=-640..-380 预留同尺寸禁入矩形，四周实体混凝土围墙。正式落位时只检查该地是否与现有固定设施冲突，冲突则整体平移。
- 外侧实体门交互进入独立基地；围墙内没有可直接步行进入的重复基地。地图画出相同轮廓，地图传送不能穿入封闭区域。追加 F2 地标，保留旧编号。
- 异步读取/Worker 准备区块描述，主线程分时小批创建，前进方向预取，较远距离滞回卸载，取消过期任务；真实释放几何和无引用材质/纹理。
- 不能先把整座基地建完再隐藏冒充流式。全局碰撞描述常驻；尚未准备好的入口先阻挡，避免掉进未加载地面。
- 与材质服务约定 materialFor(key,roomId)、ensureRoom(roomId)、releaseRoom(roomId)，房间引用数驱动光照贴图生命周期。

- 从统一布局导出 exportAlphaBake150()：roomId、bounds、materialSet、fixedLights、朝内 surfaces {o,a,b}、结构及大件家具遮挡体。

- 走廊也必须有对应烘焙覆盖。静态灯不建立庞大实时灯池；仅保留玩家动态灯及确有必要的效果。
