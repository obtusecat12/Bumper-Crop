Backrooms V98 — Windows 10/11 x64 离线电脑版

安装：双击 Backrooms-V98-Windows-Setup.exe，完成后从桌面启动。
无需管理员权限。需要电脑已安装 Microsoft Edge，以及支持 WebGL2 的显卡和驱动。
全部游戏、关卡、模型、声音和贴图均随包提供；游戏无需连接网站。
为减小安装包，使用现有 Edge 的渲染引擎，不捆绑额外浏览器。

启动为全屏窗口；F11 切换全屏，Alt+F4 退出。
F2 打开目的地菜单，可选择 Level 10 湖岸旱厕与营地居民。
游戏服务只监听本机 127.0.0.1:19898，关闭游戏后服务退出。
设置独立保存在 %LOCALAPPDATA%\BackroomsV98\BrowserProfile。
卸载保留设置；如需清空，请在退出游戏后手动删除上述目录。
请在安装更新或卸载前关闭游戏。

此版本未进行代码签名。已交叉编译并校验打包内容；当前构建环境不是 Windows，未在 Windows 实机验证启动。
