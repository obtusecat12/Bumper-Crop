# Level 0 · V96 参考对照与实现记录

## 本轮范围

修复坡面浮水；将马尼拉从单一地标扩展为确定性的稀有房间分布；加入两类低概率假窗；按附件 4–7 建立向下的房间剖面天井。所有向上的楼梯均未建立。原始七张附件、四张生成放大图和六幅新材质原图保存在 `art-source/level0-v96`。

放大图只辅助辨认。结构以原始附件和用户文字为准；生成放大图中的楼梯没有被带入模型。这里的实机证据来自本地 Chrome / SwiftShader 运行真实 Three.js 场景，不是生成图，也不是硬件帧率或获奖品质认证。

## 生成与 bug 修复

- **浮水**：取消统一 `y=.018` 的悬浮平面。湿润网格经过旋转后逐顶点采样权威地面高度，缓存于区块，并在墙体足迹处去除穿墙三角形；区块卸载时释放几何。黑暗区水碗保留合理的水平水位，调整范围以符合凹面。
- **马尼拉**：256m 生成单元中以 14% 概率产生候选，约每 46.8 万平方米一间，固定地标保护区除外。64m 中心抖动保证相邻候选至少有一轴相距 192m，超过复用场景的加载直径。在原点 ±1300m 的正方形内实际有 **12 间程序生成房间**，另加原始固定房间。
- **房间复用**：原始照片房间保持不动，额外房间使用可平移的独立实例；墙纸原点、门轴、光源、碰撞、地图与地板/吊顶开孔一起移动，各坐标保存各自门状态。
- **假窗**：合格长墙面上总触发率 0.6%，两类各 0.3%；按种子固定位置。黑窗有暗背板、双扇格框、窗台与小灯；墙面格栅不遮掉后面的墙纸。与插座、霉斑和电箱留出位置。
- **F2**：原有 0–19 索引保持；20–22 为天井三处边缘，23 为稀有马尼拉，24–25 为两类实际生成的假窗。
