# Tide Garden generated artwork

Eighteen selected independently generated originals are integrated: four painted tropical lagoon murals, four closed-bar material/notice images, four transparent foliage cutouts, two carved Tiki portraits plus one carved wood surface, and three lava/flagstone/ceiling surfaces. Exact prompts, source images, refinement candidates and per-group provenance are retained in the subdirectories. Image production was delegated; scene code and UV integration were written by the root agent.

The supplied references were inspected directly. They guide composition, object relationships, material character and lighting; generated replacements are not literal extracted photographic pixels. Derived normal, height, roughness and AO maps are luminance-based estimates. Native source sizes are retained; runtime versions use WebP with the original alpha where required. Portrait alpha silhouettes and annotated face landmarks govern continuous three-dimensional mesh UVs in tiki-garden-sculpture-uv-v86.js.

The downloaded image prompt skill used for generation is preserved in this directory. Existing approved V85/V81 artwork is reused where unchanged, including the ten-image loading album and thatch/water art. See tests/tiki-garden-v86/REVIEW.md for local rendered comparisons.
