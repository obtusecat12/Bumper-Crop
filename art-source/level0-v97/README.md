# Level 0 V97 source artwork

Four independent built-in ImageGen base-color textures and four conservative image enlargements are stored here. Exact prompts and source provenance are preserved.

- fiberglass-porous: pale yellow glass wool with irregular black pores, frayed rims and water staining. Use on low-profile torn batts and vertical wall cavity insertions. Geometry should contain the broad torn edges and sag; texture handles fine fibers and pores.
- red-gingham-plastic: 12 check squares per axis, brick-red and ivory cheap vinyl. Use low roughness on the tablecloth only; model the cloth hanging/cut edge separately.
- mattress-ticking: aged cream, blue-gray pinstripes, diamond quilting and water stains. Actual torn opening and steel springs should be geometry.
- timber-cut-grain: raw softwood grain along the vertical texture axis. Map stud grain along its long axis and use a separate cap UV or a turned narrow crop for raw sliced wall ends.

Original generated PNG assets are 1254 × 1254 pixels and intended for archival source use. Runtime maps should be downsampled and compressed; do not ship reference enlargements or PNG masters. Base colors are interpretive art, not measured PBR scans. Any normal/roughness derivatives are estimated.

Reference enlargements 4–7 preserve compositions and are for easier inspection only. Microdetail introduced by generation cannot establish original geometry. Keep original attachments as the source of structural truth.
