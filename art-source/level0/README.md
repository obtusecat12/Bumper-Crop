# Level 0 surface provenance

Seven independent albedo artworks were generated for this addition: three small-pattern yellow wallpapers, beige/brown Berber carpet, acoustic ceiling tile, fiberglass batting, and a wet-carpet puddle surface. The source PNGs and exact prompts are retained here. The prompts use the user-supplied imagegen prefix; `prompt-skill.md` records that supplied workflow.

Runtime albedos are 1024px JPEG derivatives under `dist/assets/level0`. Six periodic tangent-space normal maps were estimated from luminance gradients. These are artistic approximations, not measured material scans. The puddle shader adds procedural ripples and an analytic ceiling-light reflection; it is not a full scene reflection capture.

Architectural/lore reference: https://backrooms-wiki-cn.wikidot.com/latest:level-0 and the seven user attachments. Generated artwork is independent of the wiki photographs. Raised arch windows, monotonous yellow rooms, column halls, pits, blackouts and red areas follow those references; implementation-specific almond water and F2/map navigation follow the user's game requirements.
